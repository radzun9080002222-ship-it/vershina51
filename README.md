# Вершина — Мурманск

https://vershina51.ru/

Yandex Object Storage, отдельная автопубликация GitHub Actions. Hero — сгенерированная иллюстрация с видом на гостиницу «Арктика» и площадь Пять Углов; точная квартира и реальный заказ не заявляются. Схема: белый фон, текст слева, фото 4:5 справа.

`pnpm install --frozen-lockfile`, `pnpm run build`, `node scripts/assert-ready.mjs`. Тарифная группа: ordinary; минимум 6 000 ₽ один раз на общую сумму, пустой расчёт 0 ₽.

Рекламные URL с UTM ведите сразу на основной домен: www-редирект теряет query string.
