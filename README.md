# Вершина — Мурманск

https://vershina51.ru/

Yandex Object Storage, отдельная автопубликация GitHub Actions. Hero обновлён 16.11.2026 по референсу владельца: крупный уютный диван, чистый деревянный стол и светлая гостиная после уборки; городской вид Мурманска — фон за окном. Файл hero-murmansk-clean-apartment.webp, 1120×1400, без обрезки композиции. Это сгенерированная иллюстрация, не реальный заказ и не конкретная квартира. Схема: белый фон, текст слева, фото 4:5 справа. OG-превью сохранено отдельно, эта правка относится только к основному фото.

`pnpm install --frozen-lockfile`, `pnpm run build`, `node scripts/assert-ready.mjs`. Тарифная группа: ordinary; минимум 6 000 ₽ один раз на общую сумму, пустой расчёт 0 ₽.

Рекламные URL с UTM ведите сразу на основной домен: www-редирект теряет query string.
